Put one folder per consenting student here, named by student ID, containing 3-5 clear
front-facing photos, e.g.

  data/roster/22CS001/1.jpg
  data/roster/22CS001/2.jpg
  data/roster/22CS002/1.jpg

Then run:  python -m smartattend enroll
Photos in this folder are git-ignored; only embeddings are stored in models/roster.npz.
